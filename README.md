# PDF Editor

A desktop PDF editor for Windows, macOS and Linux. Drop PDFs or images in, merge them, rearrange / rotate / delete pages, add text, draw and highlight, cover content with whiteout, and sign. Everything runs locally.

> Work in progress. See `docs/PROGRESS.md` for the current milestone.

## Development

```bash
npm install
npm run dev        # Electron app with hot reload
npm run dev:web    # renderer only, in your browser
npm run check      # typecheck + lint + unit tests
npm run test:e2e   # Playwright UI tests
npm run package    # build installers into release/
```
